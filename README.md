##  My Learning Experience

As a fresher, this project gave me practical exposure to full-stack application development.
While building SpendWise, I learned how different parts of a web application work together, including:

- Building a frontend using React.js
- Creating backend APIs using Node.js and Express.js
- Designing and working with a MySQL database
- Connecting the frontend, backend, and database
- Understanding how HTTP requests and REST APIs work
- Implementing user authentication and authorization
- Understanding how user data is stored and retrieved from a database
- Using Git and GitHub for version control
- Debugging errors and testing application features

I also used AI tools as a development assistant during the project. I used them to understand concepts, explore implementation approaches, debug errors, and learn from different solutions.
The most valuable part of the project was not just creating the application, but understanding how the frontend, backend, API, authentication, and database work together as one complete system.
Building this project was a fun learning experience and gave me more confidence to work on full-stack applications.
